# Recorded-motion validation of seismic first-passage reliability

[Download the data (ZIP)](./Recorded_motion_validation_data.zip)

The archive contains the record list, simulated peak interstorey drifts and test predictions used in Section 5.7 of *Physics-guided multifidelity temporal surrogates with small-sample correction for seismic first-passage reliability*. The comparison uses 200 test records from 156 earthquakes and a separate set of 32 calibration records. Each record was evaluated at four ground-motion intensities.

The file descriptions and units are given in `README.txt` inside the archive. Ground motions and station metadata are from [ESM25](https://doi.org/10.13127/ai/esm25). The source networks are identified in `records.csv`.
